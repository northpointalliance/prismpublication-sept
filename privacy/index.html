Privacy

What this site actually collects, why, and who sees it -- matched to what the code does, not generic boilerplate. If a line here stops being true, it's a bug in the policy, not a footnote. Email info@prismpublication.com if something looks wrong.

By Daniel Rosenthal. Last updated 17 September 2026.

What does this site collect?

If you submit an ad campaign: brand name, work email, category, card title, description, destination URL, button text, optional keywords, and an optional budget note. This is stored in a Cloudflare D1 database so it can be reviewed and, if approved, matched against questions on run-ads.

If you pay the $5.00 submission fee: the payment itself is handled entirely by PayPal. This site never sees or stores your card number, PayPal password, or any other payment credential. What we do store is the PayPal order ID and the confirmed amount, so a submission can be tied to a verified payment.

If you use the "test your ad" checker on run-ads or the homepage demo: that text is sent to the matching function to compare against approved ad creative, and the result is returned to your browser. It is not written to any database or log. It is not stored anywhere after the request completes.

If you use the live chat on run-ads: your question text, a hashed version of your IP address (not the IP address itself), a random session ID generated in your browser, and whether a sponsored card matched are stored in the same Cloudflare D1 database, so matching quality can be reviewed and improved. Nothing about this is linked to your email, name, or any account -- there is no account. Don't type anything into the chat you wouldn't want stored as text.

General site visits: Google Analytics (a standard, cookie-based analytics tool) runs on every public page except the internal admin review page. It collects the usual aggregate signals -- pages visited, rough location, device/browser type, referring site -- the same as most websites. Cloudflare, our host, also collects its own basic traffic analytics (visit counts, page views) automatically; this is separate from Google Analytics and doesn't involve any code on this site.

Who is this shared with?

PayPal, to process the $5.00 submission fee and any future advertiser billing. Google, via Google Analytics, for traffic measurement. Cloudflare, which hosts this entire site and its database -- your data physically lives on Cloudflare's infrastructure. Nobody else. This site doesn't sell data, and doesn't share ad-submission details with anyone beyond what's needed to review and, if approved, run the campaign you submitted.

How long is it kept?

Ad submissions are kept until you ask for deletion or the campaign is clearly no longer active. There's no automatic expiry built into the system yet -- if you want a submission removed, email info@prismpublication.com and it will be deleted from the database directly. Live-chat logs (question text, hashed IP, session ID) follow the same rule -- no automatic expiry yet, deleted on request, though since they're not linked to an email or name there's no way to find a specific chat log without you telling us roughly when you sent it. Analytics data retention follows Google Analytics' and Cloudflare's own standard retention settings, not anything custom to this site.

What are your rights?

You can ask to see what's stored about you, correct it, or have it deleted. Email info@prismpublication.com with the email address you submitted under, and it will be handled directly -- this is a small, single-operator site, not a company with a formal request portal, so expect a real reply from a real person, not an automated ticket system.

Cookies

Google Analytics sets cookies to distinguish visitors and sessions. This site does not set any other cookies of its own. No login system exists on the public site, so there's nothing to keep you "signed in" to.

Where is this hosted?

Cloudflare Pages, with Cloudflare D1 as the database. No separate server, no third-party database provider. Payment processing (PayPal) and analytics (Google) are the only other services this site's data ever touches.
